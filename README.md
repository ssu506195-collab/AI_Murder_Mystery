# GitHub Pages 前端｜V4.4

將本資料夾內所有檔案直接上傳至 GitHub Repository 根目錄，確認 `index.html` 位於根目錄。

目前只啟用第一份原創劇本《霧港山莊的最後一杯茶》。V4.4 包含五份玩家小說式角色劇本、AI 精簡事實資料、逐階段任務解鎖、個人調查筆記、左右角色立繪問答舞台與逐字顯示。

模擬模式的完整私人角色資料位於 `data/demo-private.js`，供課堂測試使用；靜態網站資料可被訪客下載，不適合正式競賽。正式 Groq 模式請部署私有資料版 Cloudflare Worker，絕不可將 Worker 或完整開發套件放入公開 GitHub。
